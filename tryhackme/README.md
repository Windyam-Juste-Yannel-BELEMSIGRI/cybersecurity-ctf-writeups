# TryHackMe

Mes notes de salles. Une salle = un dossier avec `index.tex` (la source) et `index.pdf` (compilé). Les autres fichiers (`.aux`, `.log`, `.toc`...) sont générés par LaTeX.

| Salle | Ce que ça entraîne |
|---|---|
| Defensive Security Intro | Le cycle SOC : voir l'attaque sur le tableau de bord, la bloquer, enquêter sur l'attaquant |
| Offensive Security Intro | Trouver les pages cachées d'un site avec `dirb` |
| Search Skills | Chercher de l'info : Shodan, VirusTotal, bases de CVE, opérateurs de recherche |
| Linux Fundamentals Pt. 1 | Les commandes de base Linux |

Prochaine étape : le parcours SOC Level 1.
