\section{Contexte}

Dans le labs il est question d'un site qui se charge de la gestion des transferts d'argents 
entre les clients d'une banque nommée \textcolor{red}{Fakebank}. La banque est vulnérable et l'objectif du labs est 
d'exploiter cette vulnérabilité pour réaliser une transaction bancaire frauduleuse.

\section{Réalisation}
\subsection{Etape 1 : Vérification des pages du site avec la commande dirb}
\textcolor{gray}{Que permet de faire la commande dirb ?}
La commande \textcolor{red}{dirb} permet de scanner un site web pour découvrir des fichiers et répertoires cachés.
C'est un outil de brutforce de repertoires et de fichiers sur serveur web.

Son principe est simple :
\begin{itemize}
    \item On lui donne une URL
    \item On lui donne un dictionnaire de mots (wordlist)
    \item Il essai chaque mot comme nom de répertoire ou de fichier
    \item Il regarde les réponses du serveur pour savoir si le répertoire ou le fichier existe (HTTP(200, 301, 403, 404, etc.))
    \item Il affiche les résultats qui existent
\end{itemize}

\section{Limites}
\textcolor{red}{dirb} est un outil ancien. Aujourd'hui, beaucoup de professionnels préfèrent des outils plus rapides comme Gobuster 
ou Feroxbuster, qui exploitent davantage le parallélisme et offrent plus d'options.
